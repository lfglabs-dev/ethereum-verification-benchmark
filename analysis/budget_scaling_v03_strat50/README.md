## Reproduce

```bash
uv venv .venv-fit && uv pip install --python .venv-fit/bin/python numpy scipy matplotlib
.venv-fit/bin/python -I analysis/budget_scaling_v03_strat50/fit_scaling.py \
    --input output/budget_scaling_v03_strat50     # <provider>__<model>/ cascade dirs
```

Options: `--finished` (models with a complete p01–p08 cascade; default Astra,
Terra, Luna; all other model dirs are fitted but flagged `partial`),
`--bootstrap 1000`, `--seed`, `--jobs`, `--exclude`, `--no-curate`. About 3
minutes on 8 cores for 1000 replicates of both effort units.

Outputs, all regenerated by that command:

| `data/<model>/cascade_summary.csv`, `cascade_results.json` | curated copies of the cascade output (`run_dir` reduced to its basename) |

## Models

**Per-task survival (shared-shape test).** A task first solved at profile k is
interval-censored between its cumulative spend before and after k; an unsolved
task is right-censored at its total spend.
`P(solved by effort e) = A·Φ((ln e − μ)/σ)`. H1: A, μ, σ per model; H2: shared
σ; H3: shared σ and A. Fitted on the three finished models; a sensitivity fit
with all six is also reported.

**Panel curve (site form).** `S(E) = 1/(1+(kHalf/E)^α)` on cumulative panel
tokens, least squares, A = 1 (as on `/benchmark`). Running the same code on the
v0.1 MiniMax cascade gives kHalf 4.62M, α 1.185, reproducing the site's
4.6M / 1.19.

**Mapping.** A logistic in ln E with slope α and a normal with sd σ match when
α = π/(σ√3) (equal sd) or α ≈ 1.702/σ (closest CDF); kHalf = exp(μ) when A = 1.
The per-task σ and the panel α are *not* interchangeable: μ, σ describe the
effort spent on one task, kHalf, α the cumulative effort of the whole panel,
which also pays for every failed attempt on tasks that are never solved. The
panel log-normal fit (`panel_fits.<m>.lognormal_A1`) gives the like-for-like
conversion; e.g. Astra panel σ 1.62 → α 1.12 (sd match) vs direct fit α 1.06.

Shared shape (finished models): H3 preferred by AIC (ΔAIC H2 +3.6, H1 +7.6);
LRT H2 vs H1 p = 0.99, H3 vs H2 p = 0.83, H3 vs H1 p = 0.98. Shared σ = 2.18
[0.86, 3.17], shared A = 1.00 [0.44, 1.00]. H3 medians: Astra 269k, Terra 358k,
Luna 900k tokens per task; Luna needs 3.4× [2.1, 6.0] Astra's effort, Terra
1.3× [0.9, 2.0]. The all-six sensitivity fit also prefers H3 (H3 vs H1 p = 0.999).
Same conclusion in requests (H3 preferred, H3 vs H1 p = 0.92).

Caveats: with ≤ 50% solved, the ceiling A is not identified (CIs reach the
1.0 bound); the LRT with A on the boundary is conservative; 50 tasks give wide
CIs on σ, so "same shape" means "no evidence of different shapes".
